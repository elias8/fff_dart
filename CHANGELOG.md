## 0.1.0

- Add `FileFinder` lifecycle management, scan progress, and index restart.
- Add fuzzy file, directory, and mixed search with root-relative glob filtering.
- Add literal, regex, fuzzy, and multi-pattern content search.
- Add filesystem watch streams with detached event data.
- Add Git status refresh, query history, and typed health diagnostics.
- Support Linux, macOS, and Windows through the pinned FFF v0.11.0 library.
